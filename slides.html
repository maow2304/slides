5️⃣ OOP ① Encapsulation + ② Inheritance

🔒 Encapsulation — ซ่อนข้อมูล + เข้าผ่าน getter

  • ✓ Person.ts:4-5 private id / protected name
  • ✓ Customer.ts:6-7 private phone, loyaltyPoints → :19-29 getters
  • ✓ Service.ts:3-5 → :13-23 อ่านราคา/ชื่อผ่าน getter เท่านั้น
  • ✓ Booking.ts:8-15 + BarberShop.ts:6 ซ่อน array bookings

🌳 Inheritance — สืบทอด ≥1 (เรามี 2)

  • ✓ Customer.ts:4 class Customer extends Person + :10 super()
  • ✓ Barber.ts:4 class Barber extends Person + :9 super()
  • ลูกได้ getId/getName ฟรีจากแม่ ไม่เขียนซ้ำ — ลด duplication สมเหตุสมผล (คน 2 ประเภทในระบบจริง)
